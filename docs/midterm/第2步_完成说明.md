## 1. 程序功能与逻辑

[preprocess.py](../scripts/preprocess.py)支持单张图像和CSV批量输入，流程为：读取并纠正EXIF方向 → 透明图合成白底（如有） → 灰度 → 统一极性 → ROI裁剪 → 等比例缩放 → 居中补边 → 导出PNG及浮点数组。

- `load_rows`、`validate_rows`：读取参数或标签表，检查字段、编号唯一性和标签合法性。批量digit样本须有0～9真实标签；单张调试可不提供标签，程序不会自行推断。
- `transform`：auto模式以边缘灰度中位数≥128判断浅色背景并反色。随后按当前ROI阈值144定位前景包围框，最长边缩放至20，使用LANCZOS插值并居中到28×28黑色画布。ROI按左、上、右、下记录，右/下边界不包含在内。
- `run`：逐张处理并保存PNG和NPY；写入新索引及JSON报告。背景单独跳过，空白、损坏及缺失文件明确记录；批量中单张失败不会阻止其余样本处理。
- 输入只读，输出目录须为新的或空目录。固定图像与参数产生可重复的图像输出，运行报告时间戳随执行变化。

阈值只用于寻找ROI，最终图像保留灰度；PNG为28×28、L模式，NPY为CHW的1×28×28、float32，数值为像素除以255。NPY不含批次维度，不是HLS定点输入。自动极性界限128与ROI阈值144是不同概念；几何居中按包围框，不是质量中心校正。

[check_preprocess.py](../scripts/check_preprocess.py)构造形状、极性、位置、颜色、透明度、方向和低对比度样例，以及空白、背景、损坏、缺失文件等情况，通过实际CLI检查数组、索引、退出码、原图哈希和覆盖保护。这些人工样例与正式自采数据分开，不能用于统计识别准确率。

## 2. 当前使用方法

已使用Python 3.12.14、Pillow 12.3.0、NumPy 2.3.5，未安装新依赖。当前机器可用环境：

```powershell
Set-Location 'D:\A_lessons\26_xxq\Project'
$projectPython = 'C:\Users\ASUS\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
& $projectPython -B scripts/preprocess.py --help
```

当前标签表有10条真实样本记录。以下命令使用当前默认144生成一批新结果；示例run_003尚未创建，执行前仍应检查目录为空或不存在：

```powershell
& $projectPython -B scripts/preprocess.py --csv data/self_collected/label.csv --output-dir data/self_collected/processed/run_003
```

单张示例（同样须使用新的或空目录）：

```powershell
& $projectPython -B scripts/preprocess.py --input data/self_collected/original/3.jpg --sample-id sample_0004 --label 3 --output-dir results/preprocess/manual_digit3
```

| 参数 | 当前含义与默认值 |
|---|---|
| `--input` / `--csv` | 单张图像 / 批量索引，二选一；CSV路径相对于该CSV所在目录解析 |
| `--output-dir` | 必填，新的或空的输出目录 |
| `--sample-id` | 仅单张模式；默认sample_0001 |
| `--sample-type` | 仅单张模式；默认digit，可选background |
| `--label` | 仅单张模式；人工已知的0～9，调试可留空；background必须留空 |
| `--polarity` | 默认auto；可选dark-on-light或light-on-dark |
| `--threshold` | 当前默认144，允许1～254；复现初始参数需显式传128 |
| `--inner-size` | 默认20，允许1～28；画布始终28×28 |

退出码0表示没有读取或处理错误，但可能有no_foreground或skipped_background；1表示存在逐样本error，其他样本仍继续；2表示配置、索引或输出目录问题。须结合processing_report.json的状态计数判断结果，不能只看退出码。

若需重新运行现有受控检查，指定新的工作目录：

```powershell
& $projectPython -B scripts/check_preprocess.py --work-dir data/preprocess_checks/run_002
```

该命令未在默认值改为144后执行；现存24项通过记录对应初始0.2.0版本。检查脚本会有意测试损坏、缺失文件及非零退出码，不能把这些预设负例当成真实数据故障。

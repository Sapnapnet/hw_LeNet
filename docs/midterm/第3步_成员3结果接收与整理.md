# 第3步：成员3结果接收与整理

完成日期：2026-09-07。范围：按用户批准方案接收、核查并整理成员3的准确率与定点配置，复用其图表。第3步整体仍在进行，成员4工作暂停。

## 1. 完成内容

已核查成员3交付包，整理Float及W8～W16共10条准确率记录、W12/A12配置说明、选择依据和可引用文案，并将已有位宽—准确率图复制至展示目录。已更新项目入口、总方案验收状态和中期汇总。

结果为Float 98.97%，W12/A12（累加器32位）98.94%，下降0.03个百分点。完整结果、来源、图注和限制集中记录在[定点量化汇总](../results/midterm/member3/quantization_summary.md)。

## 2. 方法与核查范围

1. 运行交付包自带的`tools/verify_package.py`，结果为`PACKAGE VERIFICATION: PASS`；另按MANIFEST核对10个条目的路径、字节数和SHA256，并记录包含MANIFEST在内全部11个原始文件的哈希。
2. 用临时JavaScript整理程序和Artifact Tool读取原始CSV，逐行校验`correct/total`、Float与Fixed差值、位宽顺序和配置。核对选定行与`run_summary.json`、`quant_config.json`，以及独立整数验证JSON与运行摘要的一致性。
3. 保留原始数据，生成独立CSV：准确率从比例转换为百分数值；差值保留百分点；加入配置标识、选定标记和源文件位置。通过单元格读取与表格预览核查后输出UTF-8 CSV；临时程序和预览不作为项目交付物。
4. 核对图中9个点、Float基准线和W12标记与原始数据一致，原样复制PNG，校验复制前后SHA256相同。
5. 为文字结论标明证据边界，并留下[verification.json](../results/midterm/member3/verification.json)，便于后续确认输入版本及成果是否变化。

本次属于交付结果的接收核查，未重跑10,000张图像推理、训练或HLS实验。checkpoint和实现代码的哈希仅作版本引用，未核查包中不存在的对应实体文件。未修改成员3原始材料、预处理代码或实拍数据。
